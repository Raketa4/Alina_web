# Редизайн сайта Алины Хоняк: меню-плитка и новая структура разделов

Дата: 2026-10-25
Статус: согласовано с заказчиком в диалоге, ждёт утверждения документа
Предыдущая спека: [docs/specs/2026-08-31-alina-khoniak-site-design.md](../../specs/2026-08-31-alina-khoniak-site-design.md)

## 1. Зачем

Сайт переделывается по образцу https://jkim.ru/: спокойный минималистичный
стиль, много белого, гротеск, а главное — **меню, которое открывается
поверх страницы плиткой из крупных квадратов**. Заказчику понравились
именно стиль и открытие меню.

Одновременно меняется структура: продажа уходит в отдельный магазин
(появится позже), поэтому «Каталог», цены и статусы наличия с сайта
убираются. Сайт становится чистым портфолио: серии, проекты, мастерская,
об авторе.

## 2. Цели, не-цели, анти-цели

**Цели**
- Новое меню-плитка (раздел 4) — точно как в утверждённом макете.
- Новая структура из 8 разделов (раздел 5).
- Единый стиль всех страниц: белый фон, шрифт Onest.
- Контент по-прежнему правится в `data/*.json` без правки кода.
- Форма связи реально отправляет письмо на alinakhoniak@gmail.com.

**Не-цели**
- Магазин, корзина, оплата — не делаем; в меню только квадрат-заглушка.
- Реальный контент для новых разделов (Мастерская, Преподавательская,
  Кураторская, Публикации, фото главной) — не пишем, ставим заглушки.
- Окончательный английский перевод новых текстов — черновой или копия RU.

**Анти-цели (провал, даже если «работает»)**
- Меню отличается от утверждённого макета (размеры, порядок, шрифт, фон).
- Под работами в сериях появляются подписи, цены или статусы.
- Использованы чужие изображения из интернета (авторские права) —
  заглушки только из работ Алины.
- Подключены шрифты jkim.ru (ABC Oracle, OT Alpha) — они платные.

## 3. Ограничения

- Остаётся текущий технический подход: статический HTML + CSS + ванильный
  JS (ES-модули), без сборки, хостинг GitHub Pages
  (`https://raketa4.github.io/Alina_web/`, деплой из `main`, корень).
- Двуязычие RU/EN сохраняется (`i18n/*.json`, поля `ru`/`en` в `data/*.json`;
  `scripts/check.py` проверяет совпадение ключей).
- Все пути относительные (сайт живёт в подпапке `/Alina_web/`).

## 4. Меню — утверждено по макету

Эталон: [2026-10-25-menu-mockup.html](2026-10-25-menu-mockup.html)
(открывать через локальный сервер из корня репозитория). Фон меню —
`assets/photos/menu-bg.jpg` (фрагмент картины Алины с гладиолусами).
Переносить поведение и пропорции из макета, код макета — черновой.

- **Шапка** фиксированная; на страницах — белый фон, при открытом меню —
  прозрачная, имя и ✕ лежат прямо на картине (как в макете). Слева «АЛИНА ХОНЯК» заглавными
  (ссылка на главную), справа кнопка-бургер из трёх одинаковых полосок
  (по 2px, шаг 8px). Рядом с бургером — маленький переключатель RU / EN.
- **Открытие:** плавно (≈0.45 с) появляется полноэкранный слой с фоном
  `menu-bg.jpg` (`cover`, по центру). Полоски бургера анимируются в крестик ✕.
- **Плитка:** 8 белых квадратов, **2 в ряд, 4 ряда**, стоят вплотную;
  рамка 2px прозрачная — между квадратами видна тонкая полоска картины.
  Размер квадрата подбирается так, чтобы вся плитка **вписалась в экран
  без прокрутки** (по высоте и ширине), плитка по центру. На телефоне
  квадраты по ширине экрана (2 в ряд), слой прокручивается.
- Квадраты появляются по очереди (задержка ~0.05 с на каждый).
- **Текст в квадрате:** только название, по центру по горизонтали,
  с небольшим отступом от верха (~8% стороны). Без номеров и подписей.
  Шрифт Onest. Размер текста масштабируется от размера квадрата.
  Наведение — лёгкое тёплое затемнение фона квадрата.
- **Порядок квадратов** (слева направо, сверху вниз):

  | ряд | левый | правый |
  |---|---|---|
  | 1 | АЛИНА ХОНЯК → главная | Мастерская |
  | 2 | Об авторе (+ подразделы) | Магазин |
  | 3 | Серии | Инфо |
  | 4 | Проекты | Контакты |

- **Об авторе** — единственный квадрат с подпунктами под названием:
  CV, Artist statement, Преподавательская деятельность, Кураторская
  практика, Публикации. Само название ведёт на страницу «Об авторе»,
  каждый подпункт — на свою страницу.
- **Магазин** — пока без ссылки (неактивный квадрат); позже вписать URL
  в `data/site.json` (поле `shop_url`), и квадрат станет ссылкой во внешний
  магазин.
- Закрытие: крестик, Esc, переход по ссылке. Пока меню открыто, прокрутка
  страницы под ним заблокирована, фокус клавиатуры не уходит за меню.

## 5. Страницы

Общее для всех: белый фон `#FFFFFF`, текст почти чёрный, шрифт Onest
(Google Fonts, кириллица) — **везде**, шрифты с засечками
(Cormorant Garamond, EB Garamond) уходят. Внизу каждой страницы скромный
подвал: © Алина Хоняк и ссылки на соцсети.

Общий шаблон «список → карточка» для Серий и Проектов:
- **Список:** сетка обложек; под каждой — название и короткое описание.
- Нажатие на обложку открывает экран этой серии/проекта.

| Страница | Содержимое |
|---|---|
| **Главная** | Большое фото «Чувашской свадьбы» + текст к нему; ниже — ещё фотографии и описание. Пока фото — фрагменты «Свадьбы» и другие работы Алины (заглушки). |
| **Серии** (список) | Шаблон выше. Сейчас две серии: «Горы и море», «Портреты». |
| **Серия** | Только изображения работ, **без каких-либо подписей**. Нажатие на изображение — просмотрщик (ниже). |
| **Проекты** (список) | Шаблон выше. Сейчас один проект: «Чувашская свадьба». |
| **Проект** | Фотографии и текст. |
| **Мастерская** | Одна страница: фотографии процесса + одно общее описание. Пока заглушки. |
| **Об авторе** | Портрет (`assets/photos/artist-portrait.jpg`) + короткий рассказ. |
| **CV** | Текст из `data/cv.json` (образование, выставки, награды). |
| **Artist statement** | Текст из `statement` в `data/site.json`. |
| **Преподавательская деятельность** | Фото + текст. Текст — из `cv.json` → `teaching`, фото — заглушки. |
| **Кураторская практика** | Фото + текст. Текст — из `cv.json` → `curatorial`, фото — заглушки. |
| **Публикации** | Фото + текст. Текст — из `cv.json` → `publications`, фото — заглушки. |
| **Инфо** | Согласие на обработку персональных данных; обмен и возврат. |
| **Контакты** | Ссылки на Telegram, Instagram, VK, почта alinakhoniak@gmail.com; форма связи (ниже). |

**Просмотрщик изображений (серии и, по желанию строителя, проекты):**
открывается поверх страницы крупно; изображение можно приближать
(колесо мыши / двойной клик, щипок на телефоне) и перетаскивать;
листание стрелками и свайпом; закрытие — крестик, Esc, клик по фону.

**Форма связи:** поля имя, e-mail, сообщение + галочка согласия на
обработку персональных данных (ссылка на «Инфо»). Отправка через
FormSubmit (`https://formsubmit.co/alinakhoniak@gmail.com`), без
регистрации. При первой отправке FormSubmit пришлёт на эту почту письмо
с подтверждением — Алина один раз нажимает ссылку. Адрес почты —
в `data/site.json` → `email`.
**Проверка формы:** строитель реальных писем не отправляет — проверяет
только разметку, поля, валидацию и адрес `action`. Живую отправку и
подтверждение FormSubmit заказчик проверяет сам после публикации.

## 6. Данные и миграция

- `data/projects.json` сейчас содержит три записи. Новое разделение:
  `mountains-and-sea`, `portraits` → **серии**; `chuvash-wedding` →
  **проект**. Как это хранить (поле `kind` или два файла) — решает строитель;
  `slug`-и сохранить.
- У серии/проекта появляется короткое описание для списка
  (отдельно от полного текста проекта).
- `catalog.html`, `js/catalog.js`, цены и статусы
  (`available / reserved / sold`) — удаляются. **Данные о работах
  (название, год, техника, размер) не теряются:** переносятся в записи
  серий (для `alt`-текстов и будущего магазина), но на сайте нигде не
  показываются — ни под работой, ни в просмотрщике (решение Claude).
- `data/info.json`: остаётся `privacy`, но текст переписывается: форма
  теперь отправляет данные через сторонний сервис FormSubmit (старый текст
  «данные не собираются, форма открывает почту» станет неправдой).
  Добавляется «Обмен и возврат» — **заглушка, явно помеченная как черновик**,
  до появления магазина. Оба текста — черновики Claude, Алина проверяет
  перед публикацией. Пункты про покупку, оплату, доставку, подлинность —
  убираются (решение Claude: продажа уходит в магазин).
- Работа ведётся в отдельной ветке и попадает в `main` одним слиянием,
  чтобы живой сайт не был наполовину старым (решение Claude).
- Новые разделы (Мастерская, фото главной, фото подразделов «Об авторе»)
  получают свои поля в JSON, чтобы заменить заглушки без правки кода.
- Обновить `sitemap.xml`, канонические ссылки, `README.md`,
  `docs/content-guide.html`, `scripts/check.py` под новую структуру.
- Старые адреса (`catalog.html`) — на усмотрение строителя: удалить или
  оставить страницу с переходом на «Серии».

## 7. Что решил Claude (заказчик видел и согласился в диалоге)

- Заглушки изображений — только работы Алины с сайта.
- FormSubmit для формы.
- RU / EN — в шапке рядом с бургером.
- Подвал на каждой странице.
- Листание в просмотрщике.

## 8. Оставлено строителю

- Устройство файлов страниц (отдельные HTML на каждую страницу или общий
  шаблон серии/проекта по `?slug=`, как сейчас `project.html`).
- Шапка/меню продублированы в каждом HTML или вставляются из JS.
- Типографическая шкала, отступы, сетка обложек, анимации — в духе
  jkim.ru и макета меню.
- Реализация зума в просмотрщике (своя или небольшая библиотека с CDN
  без сборки).
- Английские формулировки новых интерфейсных строк.
