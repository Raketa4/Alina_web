Как обновлять сайт

Весь текст и данные сайта лежат в простых файлах. Их правят в текстовом редакторе — программист для этого не нужен.

0 Общий порядок действий

Почти весь контент — в папке data/, в файлах формата JSON. Открываются любым редактором (Блокнот, Notepad++, VS Code). Картинки — в папке assets/.

  1. Открыть нужный файл, внести правку, сохранить (кодировка — UTF‑8).
  2. Если добавляли или меняли картинки работ — выполнить в папке проекта: python scripts/make_placeholders.py (создаст недостающие миниатюры).
  3. Проверить: python scripts/check.py — в ответе должно быть OK. Если есть ошибки — они названы построчно, поправить и повторить.
  4. Загрузить изменённые файлы на GitHub: репозиторий Alina_web → Add file → Upload files → перетащить файлы → Commit changes.
  5. Через 1–2 минуты сайт обновится: raketa4.github.io/Alina_web
Правила JSON — иначе сайт не соберётся

Каждое значение — в двойных кавычках "…". Между элементами списка — запятая. После последнего элемента перед ] или } запятой нет. Не удалять скобки { } и [ ]. Кавычки — только прямые ", не «ёлочки».

Все тексты двуязычные: у каждого поля есть пара "ru" и "en". Меняете русский — поменяйте и английский рядом. Тексты из нескольких абзацев — это список: каждый абзац в кавычках, через запятую.

2 Серии и проекты

Серии

Файл data/series.json — список серий. У серии: title (название), summary (короткое описание под обложкой), cover (обложка) и works — список работ. На странице серии показываются только изображения, без подписей; название, год, техника и размер работы нужны для поисковиков и будущего магазина.

Новая серия — скопировать блок серии целиком, придумать slug латиницей (он попадёт в адрес страницы) и добавить строку в sitemap.xml. Поле slug у существующих серий не менять.

Проекты

Файл data/projects.json — то же устройство: title, summary, cover, плюс text (абзацы на странице проекта) и images (список фотографий).

Картинки к работам

  1. Экспортировать фото в JPEG, большая сторона ≈ 1600 px.
  2. Положить в assets/works/ под именем <id>-full.jpg.
  3. Выполнить python scripts/make_placeholders.py — миниатюра <id>-thumb.jpg создастся автоматически.
Сейчас на сайте заглушки

Файлы в assets/works/ и портрет — временные картинки с названием на бежевом фоне. Чтобы поставить настоящие фото, положите их под теми же именами и выполните python scripts/make_placeholders.py --thumbs.

4 Меню, магазин, контакты, инфо

Меню

Восемь квадратов меню описаны в data/menu.json, названия — в i18n/ru.json и i18n/en.json (блок "menu"). Фон открытого меню — assets/photos/menu-bg.jpg: чтобы сменить картину, замените файл тем же именем.

Магазин

Когда магазин появится, впишите его адрес в data/site.json → "shop_url" (например "https://shop.example.ru"). Квадрат «Магазин» станет ссылкой и будет открывать магазин в новой вкладке. Пока поле пустое, квадрат не нажимается.

Контакты и форма

  • Почта — data/site.json → "email"; соцсети — "social" (telegram, instagram, vk).
  • Письма из формы приходят на эту почту через сервис FormSubmit. При самой первой отправке FormSubmit пришлёт на почту письмо «Activate Form» — нужно один раз нажать в нём кнопку подтверждения, иначе письма не будут доходить.
  • Если меняете почту — поменяйте её и в contacts.html (адрес в action формы), и снова подтвердите FormSubmit.

Инфо

data/info.json — «Согласие на обработку персональных данных» и «Обмен и возврат». Сейчас это черновики, их нужно проверить перед публикацией. Поле body — список абзацев.

Английский язык

Интерфейс (меню, кнопки, подписи) — i18n/en.json. Длинные тексты — поля "en" внутри файлов data/. Наборы ключей в ru.json и en.json обязаны совпадать — это проверяет check.py.

Аналитика и поисковые системы

  • Яндекс.Метрика — вписать номер счётчика в data/site.json → "metrika_id". Подключится сама.
  • Google Search Console — файл подтверждения положить в корень репозитория.
Осторожно с файлами подтверждения

Скачанные HTML-файлы иногда заражаются тегами kaspersky-labs.com. Перед загрузкой открыть файл и удалить всё, кроме исходной строки подтверждения.

Свой домен

Когда появится домен: создать в корне файл CNAME с адресом домена и заменить raketa4.github.io/Alina_web на новый адрес в canonical, og:url, sitemap.xml, robots.txt, в поле _next формы в contacts.html и в теге <base> файла 404.html.
