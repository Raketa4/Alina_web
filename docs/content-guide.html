Как обновлять сайт

Весь текст и данные сайта лежат в простых файлах. Их правят в текстовом редакторе — программист для этого не нужен.

0 Общий порядок действий

Почти весь контент — в папке data/, в файлах формата JSON. Открываются любым редактором (Блокнот, Notepad++, VS Code). Картинки — в папке assets/.

  1. Открыть нужный файл, внести правку, сохранить (кодировка — UTF‑8).
  2. Если добавляли или меняли картинки — выполнить в папке проекта: python scripts/make_placeholders.py (создаст недостающие миниатюры).
  3. Проверить: python scripts/check.py — в ответе должно быть OK. Если есть ошибки — они названы построчно, поправить и повторить.
  4. Загрузить изменённые файлы на GitHub: репозиторий Alina_web → Add file → Upload files → перетащить файлы → Commit changes.
  5. Через 1–2 минуты сайт обновится: raketa4.github.io/Alina_web
Правила JSON — иначе сайт не соберётся

Каждое значение — в двойных кавычках "…". Между элементами списка — запятая. После последнего элемента перед ] или } запятой нет. Не удалять скобки { } и [ ]. Кавычки — только прямые ", не «ёлочки».

Все тексты двуязычные: у каждого поля есть пара "ru" и "en". Меняете русский — поменяйте и английский рядом.

1 Избранные работы и тексты главной

Избранные работы

Это крупные работы в блоке «Избранные работы» на главной странице. Задаются списком в файле data/site.json, поле "featured" — это id работ из каталога, в нужном порядке (обычно 3–4 штуки).

  • Поменять состав или порядок — переставить или заменить id в списке.
  • Убрать работу с главной — удалить её id из списка. В каталоге работа останется.
  • Добавить новую работу в избранное — сначала добавить её в каталог (раздел 3), затем вписать её id сюда.
Важно

id в "featured" обязан существовать в data/catalog.json. Несуществующий id просто не покажется.

2 Портрет автора и страница «Об авторе»

Фото автора

  1. Подготовить вертикальный кадр, примерно 1200 × 1600 px, JPEG.
  2. Положить в assets/photos/ под именем artist-portrait.jpg (заменив текущий файл — имя то же).
  3. Подпись под фото — data/site.json → "portrait_credit" (сейчас «Фото: Артём Жигалов»).

Artist statement

Текст в data/site.json → "statement". Это список абзацев — каждый абзац в кавычках, через запятую. Абзацев может быть сколько угодно.

Необязательно, но желательно

Тот же русский текст дублируется в about.html между <div class="prose" id="statement"> и </div> — это запасной вариант для поисковых систем. Посетители видят версию из JSON.

CV

Образование, преподавание, выставки, награды, кураторские проекты, публикации — файл data/cv.json. Внутри каждого раздела — список записей вида { "period": "2024", "ru": "…", "en": "…" }.

3 Каталог работ

Файл data/catalog.json — список работ. Каждая работа — блок в фигурных скобках. Чтобы добавить работу, скопируйте блок и вставьте перед закрывающей ], не забыв запятую между блоками:

ПолеЧто вписать
idуникальный, латиницей. Это же имя у файла картинки.
statusavailable — в наличии · reserved — в резерве · sold — продано (у проданных кнопка заявки заменяется на «Продано»).
projectslug серии из data/projects.json: mountains-and-sea, portraits, chuvash-wedding. Если работа вне серии — убрать строку целиком.
priceнеобязательно. Без этого поля на карточке будет «Цена по запросу».
imageвсегда assets/works/<id>-full.jpg

Картинки к работе

  1. Экспортировать фото работы в JPEG, большая сторона ≈ 1600 px.
  2. Положить в assets/works/ под именем <id>-full.jpg (например mas-13-full.jpg).
  3. Выполнить python scripts/make_placeholders.py — миниатюра <id>-thumb.jpg создастся автоматически.
Заменить фото у существующей работы

Положить новый файл под тем же именем и выполнить python scripts/make_placeholders.py --thumbs — миниатюры пересоберутся из новых фото.

Изменить или убрать работу

  • Правка описания — поменять поля title, medium, size, year у нужного блока.
  • Работа продана — заменить "available" на "sold".
  • Удалить работу — удалить весь её блок (и запятую). Если она была в "featured" — убрать оттуда её id.

4 Прочие изменения

Контакты

Файл data/site.json:

  • "email" — пока пусто, заявки уходят в Telegram. Впишите адрес — кнопки «Оставить заявку» начнут открывать письмо.
  • "phone", "location" — телефон и город.
  • "social" — ссылки telegram, instagram, vk. Можно добавить behance, facebook.

Проекты / серии

data/projects.json — title, description, year, role, cover (обложка) и images (список картинок серии). Поле slug не менять — оно в ссылках и карте сайта.

Тексты страницы «Инфо»

data/info.json — разделы «Как приобрести», «Доставка», «Оплата» и т. д. Поле body — список абзацев.

Меню сайта

Пункты меню продублированы в каждом файле *.html. Если меняете названия пунктов — правьте во всех файлах. Обычно трогать не нужно.

Английский язык

Интерфейс (кнопки, подписи) — i18n/en.json. Длинные тексты — поля "en" внутри файлов data/. Наборы ключей в ru.json и en.json обязаны совпадать — это проверяет check.py.

Аналитика и поисковые системы

  • Яндекс.Метрика — вписать номер счётчика в data/site.json → "metrika_id". Подключится сама.
  • Google Search Console — файл подтверждения положить в корень репозитория.
Осторожно с файлами подтверждения

Скачанные HTML-файлы иногда заражаются тегами kaspersky-labs.com. Перед загрузкой открыть файл и удалить всё, кроме исходной строки подтверждения.

Свой домен

Когда появится домен: создать в корне файл CNAME с адресом домена и заменить raketa4.github.io/Alina_web на новый адрес в canonical, og:url, sitemap.xml, robots.txt и в теге <base> файла 404.html.
