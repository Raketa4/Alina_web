# Сайт Алины Хоняк

Двуязычный (RU/EN) статический сайт-портфолио художницы в стиле jkim.ru:
белые страницы, шрифт Onest, меню — белая сетка 2 × 4 из прямоугольников
с чёрными линиями (образец — мобильное меню liars.co).
Без сборки — чистые HTML/CSS/JS.

**Адрес:** https://raketa4.github.io/Alina_web/

## Структура

```
index.html                 главная
series.html                серии — ленты картин с подписями друг под другом; series.html#<slug> — к ленте
series-view.html           только переадресация старых ссылок ?slug= на series.html#<slug>
projects.html              список проектов      project.html?slug=      один проект (текст + фото)
studio.html                мастерская
about.html                 портрет, «Описание творчества» и «Биография» (в EN — Artist statement и CV,
                           data/cv.json): образование, педагогическая
                           деятельность, выставки, кураторские проекты, награды, публикации
cv.html statement.html     — подразделы «Об авторе» (отдельные страницы преподавания, кураторства
                           и публикаций удалены 01.11.2026 — их списки есть в CV на about.html)
info.html contacts.html 404.html

css/styles.css    — вся вёрстка, палитра и типографика в :root
js/page.js        — bootPage(): шапка/меню/подвал → язык → интерфейс → страница → аналитика
js/chrome.js      — шапка, меню и подвал (вставляются в каждую страницу из data/menu.json)
js/viewer.js      — просмотрщик с зумом для всех [data-zoom] (листает в пределах data-gallery;
                    подпись под изображением — из <figcaption> той же <figure>, как в лентах серий)
js/cards.js       — сетка обложек проектов
js/*.js           — модули страниц
data/*.json       — весь контент (правится без кода)
i18n/ru.json,en.json — словари интерфейса (наборы ключей обязаны совпадать)
assets/works/     — изображения работ: <id>-full.jpg (~1600px) и <id>-thumb.jpg (~800px)
assets/photos/    — портрет автора
scripts/          — check.py (проверки), make_placeholders.py, make_icons.py
```

## Где какой контент

| Раздел | Файл |
|---|---|
| Меню (8 прямоугольников; подразделы «Об авторе» в меню не выводятся) | `data/menu.json` + блок `menu` в `i18n/*.json` |
| Главная | `data/home.json` |
| Серии и их работы | `data/series.json` |
| Проекты | `data/projects.json` |
| Мастерская | `data/studio.json` |
| Портрет, короткий рассказ, statement, почта, соцсети, Telegram для связи (`contact_telegram`), `shop_url` | `data/site.json` |
| Тексты страницы «Контакты» | блок `contacts` в `i18n/*.json` |
| CV, в том числе преподавание, кураторские проекты и публикации | `data/cv.json` |
| Инфо: доставка и оплата, обмен и возврат, политика конфиденциальности, согласие на обработку ПД, оферта (раскрывающийся список) | `data/info.json` |

Под работой в ленте серии — подпись: «название», размер, техника, год (поля
`title`, `size`, `medium`, `year` в `series.json` — по желанию; у серий без
описаний подписей нет, а `alt` — «Серия — номер»; `id`, `src`, `width`, `height` обязательны). `width`/`height` — размер
`-full.jpg` в пикселях: по ним лента заранее знает ширину картин; `check.py`
сверяет их с файлом и подсказывает верные. Миниатюры (`-thumb.jpg`, высота
720 px) делает `python scripts/make_placeholders.py`.

## Каталог (ссылка на магазин)

Вписать адрес в `data/site.json` → `shop_url`. Прямоугольник «Каталог» станет
ссылкой (открывается в новой вкладке). Пустое поле — он неактивен.

## Контакты

`contacts.html` — блок «Связь с художником» по образцу jkim.ru/contact: почта,
Telegram и под ними форма обратной связи. Блок «посетите мастерскую» (фото
`assets/photos/studio-visit.jpg` слева, текст и кнопка «Записаться на визит»
справа) — вверху `studio.html`. Почта — `site.json` → `email`, Telegram для связи
и записи — `contact_telegram`. Тексты — блоки `contacts` и `studio`
в `i18n/*.json`.

Подвал (общий, `js/chrome.js`): «© год Алина Хоняк», под ним кружки со значками
Telegram, VK, Pinterest (ссылки — `site.json` → `social`; значки Simple Icons,
CC0) и строка про авторское право (`footer.rights` в `i18n/*.json`).

Форма отправляется обычным POST на `https://formsubmit.co/alinakhoniak@gmail.com`
(адрес также подставляется из `site.json` → `email`). После отправки FormSubmit
возвращает на `contacts.html?sent=1`. **При первой отправке FormSubmit присылает
на почту письмо активации — его нужно подтвердить один раз.**

## Проверка

```
python scripts/check.py            # все проверки
python scripts/check.py menu contacts  # только перечисленные
```
Проверяет: ключи словарей и их использование, схему данных, наличие всех
картинок, внутренние ссылки, шрифты, меню, форму, отсутствие каталога,
документы «Инфо» (порядок, реквизиты Алины, нет чужих реквизитов и контактов).

```
python scripts/browser_check.py
```
Браузерные проверки в фоновом Edge/Chrome (`tests/browser.html`): просмотрщик
не закрывается от клика по картинке, старые ссылки серий перенаправляются,
документы «Инфо» раскрываются по клику и по ссылке `info.html#id`, в EN
юридические документы помечены «только на русском»,
меню — белая сетка 2 × 4 из прямоугольников 1,3 : 1 с чёрными линиями, надписи
строго по центру, всё на экране без прокрутки — на 11 размерах (от 360×640
до 1920×1080, включая повёрнутый телефон и iPhone с панелями Safari).

## Локальный просмотр

```
python -m http.server 8000
```
Открыть http://localhost:8000/ (просто открыть файл через `file://` не
сработает — модули и `fetch` требуют http).
